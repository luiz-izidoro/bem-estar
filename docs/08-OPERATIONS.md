# Operations Runbook

## Daily health

```bash
systemctl --failed
systemctl status bem-estar-rest bem-estar-worker bem-estar-mcp --no-pager
curl -fsS http://127.0.0.1:8787/healthz
curl -fsS http://127.0.0.1:8787/readyz
```

## Logs

```bash
journalctl -u bem-estar-rest --since today
journalctl -u bem-estar-worker --since today
journalctl -u bem-estar-mcp --since today
```

Never enable debug logging that serializes health bodies.

## Ingestion backlog

Dashboard Data tab or SQLite:

```sql
SELECT status, count(*) FROM ingestion_requests GROUP BY status;
SELECT id, received_at, stream, status, error FROM ingestion_requests ORDER BY received_at DESC LIMIT 20;
```

### Pending grows

1. inspect worker logs
2. check disk space
3. `PRAGMA integrity_check;`
4. process one job manually only after preserving raw/database
5. do not delete pending rows to hide backlog

### Failed ingestion

Raw gzip remains available. Fix parser, add fixture/regression test, then reset the specific row to `pending` or provide a replay CLI in a follow-up change.

## Database health

```bash
sqlite3 /var/lib/bem-estar/bemestar.db 'PRAGMA quick_check;'
sqlite3 /var/lib/bem-estar/bemestar.db 'PRAGMA wal_checkpoint(PASSIVE);'
```

## Disk pressure

The supplied VM had roughly 12 GB free at design time, so watch raw retention and Docker logs:

```bash
df -h /
du -sh /var/lib/bem-estar/raw /var/backups/bem-estar /var/lib/docker 2>/dev/null
```

Default RAW retention is **180 days**. The installed `bem-estar-maintenance.timer` runs daily and executes `scripts/maintenance.py --prune-raw`. It only removes RAW payloads that have already been processed; canonical/derived data remains intact and the ingestion record is changed to a `pruned://` marker.

Inspect the timer:

```bash
systemctl status bem-estar-maintenance.timer --no-pager
systemctl list-timers 'bem-estar-*'
```

To preview cleanup manually, run `python scripts/maintenance.py` without `--prune-raw`.

## Backup

Use `scripts/backup.sh`, which uses SQLite's online backup command rather than copying a live WAL database blindly.

The supplied timer keeps 30 days of local SQLite/config snapshots. RAW duplication is disabled locally by default to protect disk capacity. Configure `BEMESTAR_RCLONE_REMOTE` for immutable off-host DB snapshots + RAW replication; treat local snapshots as rollback protection, not disaster recovery.

## Restore drill

Quarterly or after major migration:

1. restore into temporary directory
2. `PRAGMA integrity_check`
3. start API against restored DB on alternate port
4. query a known day/workout
5. remove test copy

## Grafana

Credentials must already exist in `/etc/bem-estar/observability.env`, generated by `scripts/generate_production_config.py`. Then:

```bash
cd /opt/bem-estar/current
./scripts/bootstrap_observability.sh
```

The target server description did not list Docker as installed. The helper installs Ubuntu's Docker/Compose packages only when needed, then pulls the pinned Prometheus/Grafana images. The core app does not depend on Docker, so observability can be stopped independently if RAM/disk pressure requires it.

Prometheus is localhost-only. Grafana is localhost-only and exposed through Caddy subpath.
